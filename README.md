## Featured App Store release

### Cyber Situational Awareness

[![Available on the App Store](https://img.shields.io/badge/Apple%20App%20Store-Available%20Now-000000?logo=apple&logoColor=white)](https://apps.apple.com/us/app/cyber-situational-awareness/id6797919717)
![TXCC State Certified](https://img.shields.io/badge/TXCC%20State%20Certified-2026%E2%80%932027-0A7E8C)
![iOS Price](https://img.shields.io/badge/iOS-%241.99-555555)

A scenario-based cybersecurity learning app designed to build practical security judgment through realistic threats, evidence review, decision practice, assessment, and feedback.

**2026–2027 State Certified Cybersecurity Training Program by the Texas Cyber Command (TXCC).**

Users work through suspicious emails, fake websites, QR codes, voice calls, identity and access risks, vendor threats, and other common attack patterns, then decide how to respond safely.

**Includes:**

- Scenario-based learning across 12 cybersecurity domains
- Situational Awareness Decision Lab
- Applied threat recognition and response practice
- Assessment and progress tracking
- Practical guidance for real-world security decisions
